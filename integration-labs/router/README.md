# React Router Real Lab

Uses React Router 8 Data Mode with Vite. This is different from the Core Playground's conceptual router demos: `createBrowserRouter`, `RouterProvider`, loaders, `useNavigation`, `useSearchParams`, `useParams`, nested `<Outlet>`, and `useRouteError` are actually running.

```bash
npm install
npm run dev
npm run build
npm run preview
```

The project loader is deliberately local/deterministic. React Router owns the routing lifecycle; the local object only supplies demo data.

Official references: React Router Data Mode installation, routing, `createBrowserRouter`, and `RouterProvider`.
