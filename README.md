# React Learning Playground

用于学习 React 的本地测试与实验代码，基于 React 19 和 Vite 构建。

当前包含 Props、Children 插槽、具名多插槽、组件组合以及 React 渲染队列等练习 Demo。

## 本地运行

```bash
npm install
npm run dev
```

常用命令：

```bash
npm run lint
npm run build
```

## 项目说明

这是一个学习用途的 playground，不是面向生产部署的完整应用。各个练习模块位于 `src/demos` 和 `src/components`。
