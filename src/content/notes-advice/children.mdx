# Review: Children 默认插槽与组合

## Verdict

审核收口完成。Note、Demo 与 Source 对 `children` / composition 的职责边界已经一致，React 19 / Compiler / 并发相关的无关宣传已移除。

## Hard gates

- **Gate A — Correctness: PASS**。Demo 不再混合声称 React 19、React Compiler 与并发能力；`children` 统一表述为 React 节点/JSX，而不是“任意 HTML”。容器职责也收窄为其实际拥有的布局、视觉外壳和关闭交互，不再泛化为完整可访问性能力。
- **Gate B — Demo Contract: PASS**。CardContainer 和 ModalLayout 都能真实观察“容器结构不变、嵌套内容变化”；Note 的 DemoReference 只要求观察这一事实，没有声称额外的 React 内部机制。
- **Gate C — Mental Model: PASS**。学习者可以区分三类决策：结构由调用者变化时使用 composition；少量稳定语义参数继续使用 props；共享可变数据单独建模 state ownership。

## Closed boundaries

1. `children` 被定义为调用位置传入的 React 可渲染节点，不再与 HTML 字符串混淆。
2. Modal 示例只宣传当前 Source 确实实现的遮罩、布局和 ESC 关闭行为；完整 dialog/focus contract 不在本课声称范围内。
3. Composition 不再被描述成无条件优于 props；Note 与 Demo 都保留显式 props 的适用场景。
4. Composition 与共享 state ownership 保持分离。

## Final status

本课无需继续增加 Demo 能力。后续若扩展完整 dialog accessibility，应作为 ModalLayout 自身的能力升级并配套可访问性测试，而不是作为 children 课程的通过条件。
