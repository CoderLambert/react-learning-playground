# State 保留、重置与 key 身份

<MentalModel title="State 绑定在 render tree 的位置与身份上">
State 不是存放在 JSX 标签或组件函数“里面”的独立盒子；React 根据组件在树中的位置、type 与 key 识别身份。同一位置保持同一身份时 state 可保留；身份变化时 React 会卸载旧子树并创建新 state。
</MentalModel>

<Boundary title="key 不只属于列表">
列表最常见，但 key 也可以用于显式区分同一位置上的不同业务实体，例如不同聊天对象或编辑表单，从而有意重置其局部 state。
</Boundary>

<AntiPattern title="在组件函数内部定义组件类型">
每次 render 都创建新的组件函数，会让 React 看到不同 type，导致子树 state 意外重置。组件定义通常应放在模块顶层。
</AntiPattern>

<Summary>
- State 由 render tree 身份定位。
- 同位置同 type/key 通常保留 state。
- 改 key 是显式重置子树的工具。
- 不要通过嵌套定义组件制造不稳定 type。
</Summary>
